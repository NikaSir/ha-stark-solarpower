# Stark panel artwork

`stark-country-1000-online.png` is an optimized transparent product likeness used only to identify the monitored UPS in the integration-owned Home Assistant panel.

`stark-hero-internet-v051.webp` and `stark-hero-boiler-v051.webp` are optimized local context plates for the selected UPS. The Internet view uses a network-room scene; the boiler view uses a heating-room scene. Live equipment, lines, labels and measurements remain separate HTML/SVG layers.

`stark-hero-internet-v063.webp` and `stark-hero-boiler-v063.webp` replace the production context plates with clean, edge-safe room photography. UI v0.6.3 keeps all live equipment, labels and measurements as separate HTML layers and no longer draws decorative power-flow lines.

- Runtime source: local integration package; no remote image request.
- Target product: Stark Country 1000 ONLINE (16A).
- The STARK Country name and product appearance belong to their respective owner.
- This repository is an independent Home Assistant project and is not an official STARK Country application.
